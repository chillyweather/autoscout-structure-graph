How AutoScout is built

AutoScout reads book sources every night and gives an editor a short list to review. Most of it is plain code. A model is called at a few fixed points, and an agent works with the editor in chat.

Three kinds of work

Every part of the app below carries one of these marks.

Code

Plain Python. The same input gives the same output. No model.

Model

A model call inside the code. Code builds the request, the model answers, code checks the answer.

Agent

The chat agent (Codex or Claude Code). It reads AGENTS.md and decides what to run.

How a request reaches the code

The editor never runs a command. The agent picks a launcher, and the launcher calls the command line.

Editorwrites in chat, in Russian
→
AgentAGENTS.md, docs/agents/contracts/
→
Launchersscripts/run-weekly, doctor, check-sources …
→
Command lineautoscout/__main__.py, autoscout/cli/
The nightly run skips the first two boxes: a timer on the run server calls scripts/run-weekly --scheduled directly, and a second timer tries once more the same night when the first run did not complete.

The run, stage by stage

The run drawn as one line, top to bottom. It stays in the code lane and steps out to the model lane only where a model is called.

Every model call has the same shape: code prepares a bounded input, the model answers, code validates the answer and drops it if a check fails. The model never writes state. autoscout/model_client.py is the one place that builds a model call, and the model pin chooses the provider per stage. Two calls go elsewhere: Jev, and a fallback provider for the PM loglines.

Jev scoring, step by step

How a book gets its fit score and how the score orders the review. One model step sits between code on both sides. Jev writes no prose: it returns probabilities for fixed answers.

Outside the run

Here the agent leads and the code is the gate. The agent proposes; a command previews the change and writes it only after the editor confirms.

Night source scouting is the most agentic part: the agent searches the web and judges on its own whether a source is a real selection with new books. Code only probes the address and enforces the onboarding gates.
